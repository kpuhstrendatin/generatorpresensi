⚙ Pengaturan Gemini API Key
Panduan mendapatkan API Key
  1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
  2. Setujui syarat layanan jika diminta.
  3. Klik Create API key, lalu pilih project atau buat project baru.
  4. Salin key yang muncul (biasanya diawali AIza).
  5. Kembali ke sini, tempel di kolom di atas, lalu klik Simpan.
Tersedia paket gratis dengan batas pemakaian. Jangan membagikan key ke orang lain dan jangan menaruhnya di file kode. Nama model bisa berubah dari waktu ke waktu; jika muncul galat model tidak ditemukan, cek daftar terbaru di ai.google.dev/gemini-api/docs/models lalu ketik manual di kolom nama model. Model Flash-Lite paling cepat dan hemat, cocok untuk tugas ini.
